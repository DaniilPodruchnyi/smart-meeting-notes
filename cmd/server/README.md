# `cmd/server`

Точка входа приложения.

Здесь происходит только инициализация:
- загрузка конфига;
- запуск логгера;
- подключение к БД и миграции;
- создание клиентов Telegram / SaluteSpeech / GigaChat;
- сборка usecase и запуск HTTP-сервера.

Бизнес-правила в `main` не хранятся: они живут в `internal/app/usecase`.
