# `internal/queue`

Простая in-memory очередь на каналах для фоновой обработки сообщений.

Зачем нужна:
- не блокировать обработчики Telegram на долгих вызовах STT/LLM;
- обрабатывать задачи воркерами;
- гарантированно отправлять ответ в нужный `chat_id`.

Бизнес-логика в очереди не хранится: она остается в usecase.
