# `internal/server`

Обертка над HTTP-сервером приложения.

Сейчас пакет отвечает за:
- запуск сервера с роутером из `transport/http`;
- корректное завершение по контексту.

HTTP-слой используется как технический endpoint (например, ping/health), основная логика работы с пользователем идет через Telegram-бота.
