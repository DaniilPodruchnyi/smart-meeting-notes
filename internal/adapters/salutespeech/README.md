# `internal/adapters/salutespeech`

HTTP-клиент SaluteSpeech для асинхронной транскрипции.

Пайплайн в адаптере:
1. загрузка файла;
2. запуск async-задачи;
3. polling статуса;
4. скачивание результата;
5. разбор ответа в структуру транскрипции.

В usecase пакет отдает готовый текст (в том числе в детальном формате, где доступно разделение по ролям).
