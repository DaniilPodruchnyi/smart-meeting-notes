# `internal/adapters/telegram`

Telegram-адаптер на `telebot.v3`.

Что делает пакет:
- регистрирует команды и обработчики сообщений;
- принимает `/start`, `/list`, `/get`, `/find`, `/smart_find`, `/chat`;
- принимает `OnVoice` и `OnAudio`, скачивает файл из Telegram и отправляет задачу в очередь;
- отправляет пользователю ответы от usecase.

Пакет занимается транспортом и форматированием сообщений, а бизнес-решения остаются в `MeetingService`.
