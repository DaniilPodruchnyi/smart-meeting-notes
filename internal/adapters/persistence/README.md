# `internal/adapters/persistence`

Слой хранения данных.

Сейчас используется подпакет `postgres/` с реализацией репозиториев на `pgxpool`.

Здесь сосредоточены:
- подключение и миграции БД;
- CRUD для пользователей и встреч;
- текстовый поиск (`/find`);
- семантический поиск (`/smart_find`) через `pgvector`.
