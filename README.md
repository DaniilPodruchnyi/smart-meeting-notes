# smart-meeting-notes

Телеграм-бот для расшифровки аудио встреч, подготовки выжимки и поиска по сохраненным материалам.

## Что умеет

- принимает голосовые и аудио сообщения из Telegram;
- делает транскрипцию через SaluteSpeech;
- формирует краткую выжимку через GigaChat;
- хранит данные в PostgreSQL;
- поддерживает два вида поиска:
  - `/find` — обычный поиск по словам;
  - `/smart_find` — семантический поиск по embeddings (`pgvector`);
- отдает полную транскрипцию по `/get <id>`.

## Основные команды бота

- `/start` — регистрация пользователя;
- `/list` — список встреч;
- `/get <id>` — полная транскрипция встречи;
- `/find <запрос>` — поиск по ключевым словам;
- `/smart_find <запрос>` — семантический поиск;
- `/chat <вопрос>` — вопрос к ассистенту.

## Быстрый запуск

```bash
make dev
```

Сервис поднимает:
- приложение;
- PostgreSQL;
- pgAdmin.

## Что важно по инфраструктуре

- Для семантического поиска нужен Postgres с `pgvector` (в `docker-compose` уже используется подходящий образ).
- Для внешних API (Telegram, Sber) нужна стабильная исходящая сеть из контейнера.
